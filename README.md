# Nubora ☁️

**Nubora** is a cloud-native IT operations platform built on Amazon Web Services (AWS).

The project is designed to provide IT teams with a centralized platform for managing support tickets, company assets, users, and operational activity while demonstrating modern cloud architecture, security, automation, and Infrastructure as Code.

## Planned Features

- IT support ticket management
- Asset and device management
- Role-based user authentication
- Serverless REST API
- File and attachment storage
- Monitoring and logging
- Automated notifications
- Infrastructure as Code
- CI/CD deployment pipeline
- Cloud security and auditing

## Planned Technology Stack
